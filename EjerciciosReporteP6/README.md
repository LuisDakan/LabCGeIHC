# Ejercicios Clase P6

## Ejercicio 1: Dado de 8 caras (Octaedro) con texturas
El objetivo es modelar un dado de ocho caras (octaedro) y aplicar texturas personalizadas a cada una de sus caras.

## Ejercicio 2: Texturizado de llantas de coche
Consiste en aplicar texturas específicas a las diferentes partes de las llantas de un coche, diferenciando entre el rin y el caucho.

## Ejercicio 3: Texturizado de partes del coche y personaje
Se busca asignar y mapear texturas a distintas partes del coche (como parabrisas, cofre y parrilla) y al personaje, utilizando materiales separados para lograr una apariencia más detallada y personalizada en la escena.
